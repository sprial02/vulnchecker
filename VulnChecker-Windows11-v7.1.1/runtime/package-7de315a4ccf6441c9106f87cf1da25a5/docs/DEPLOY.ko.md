# VulnChecker 배포 및 새 PC 설치

## 배포할 파일

`dist/VulnChecker-Windows11-v7.1.1.zip`과 같은 이름의 `.sha256.txt` 파일을 배포합니다.
이 ZIP은 프로그램과 설치 스크립트입니다. WSL·Kali·SDK·Docker 이미지 전체를 담은 오프라인 환경은 아닙니다.
개인 PC의 `runtime`, `apk-library`, 로그, 토큰, OpenCode 대화 및 추출 APK는 포함하지 않습니다.

## USB·클라우드로 전달

1. ZIP과 해시 파일을 USB 또는 승인된 클라우드에 복사합니다.
2. 사용할 Windows PC로 내려받습니다. USB 안에서 직접 실행하지 말고 PC에 압축을 풉니다.
3. 권장 위치는 사용자에게 쓰기 권한이 있는 짧은 로컬 경로입니다. 예: `C:\Tools\VulnChecker`.
4. 압축 폴더 안의 `Start.cmd`를 실행합니다. ZIP 안에서 바로 실행하면 안 됩니다.

## GitHub에 배포

1. 본인 계정으로 VulnChecker 저장소를 만듭니다. 제한 배포라면 Private을 선택합니다.
2. 저장소의 Releases → Draft a new release에서 버전 태그 `v7.1.1`을 만듭니다.
3. 배포 ZIP과 `.sha256.txt`를 첨부한 뒤 릴리스를 게시합니다.
4. 다른 PC에서는 Releases의 첨부 ZIP을 다운로드합니다. GitHub의 자동 생성 Source code ZIP과 구분하세요.

작업 폴더 전체를 통째로 올리지 말고 위 배포 ZIP만 첨부하세요. GitHub 게시에는 본인 계정의 저장소 접근 권한이 필요합니다.

## 새 PC에서 설치

지원 환경: Windows 11 x64, 인터넷 연결, 가상화 사용 가능, 같은 계정의 관리자 권한.
새 환경을 구성하므로 충분한 디스크 여유 공간이 필요합니다. 앱에서 기존 설치와 필요한 용량을 먼저 확인합니다.

1. `Start.cmd` 실행 → 약관 확인 → 자동 설치 / 이어하기.
2. 설치 시 표시되는 관리자 권한 요청을 승인합니다. 다른 관리자 계정으로 바꾸지 않습니다.
3. 재부팅 필요가 표시되면 Windows를 재부팅하고 같은 폴더의 `Start.cmd`를 다시 실행합니다.
4. 자동 설치 / 이어하기를 다시 눌러 나머지 설치를 완료합니다.
5. 실행 / 연동 탭에서 필요한 분석 환경을 엽니다.
6. OpenCode의 AI 계정 연결과 Google Play 로그인은 PC별로 직접 진행합니다.

망분리 PC는 이 ZIP만으로 설치할 수 없습니다. 회사의 WSL·Docker·가상화·외부 다운로드 제한이 있으면 해당 정책에 맞는 사전 준비가 필요합니다.

## OpenCode 종료 후 복귀

새로 연 VulnChecker 전용 창에서 `/exit`로 OpenCode를 종료하면 PowerShell에 복귀 안내가 표시됩니다.

- `oc`: 같은 작업 폴더의 이전 대화 이어서 열기.
- `oc-new`: 새 대화로 열기.
- `oc --session ID`: 지정한 대화 이어서 열기.
- OpenCode 안의 `/sessions`: 다른 대화 선택.

창을 닫았다면 VulnChecker의 같은 실행 버튼으로 다시 엽니다. 이 기능은 수정 후 새로 연 전용 창에 적용됩니다.
이미 실행 중인 구버전 창에는 명령이 추가되지 않으므로 해당 창을 닫고 다시 여세요.

## 기존 PC 업데이트

진행 중인 작업을 저장하고 VulnChecker와 전용 명령 창을 닫습니다. 기존 설치 폴더에 새 ZIP을 풀어 프로그램 파일을 교체합니다.
`runtime`과 `apk-library`는 삭제하지 않으면 유지됩니다. 직접 수정한 `config.json`이 있다면 먼저 백업하고 새 버전 설정과 비교하세요.
이미 설치된 WSL·SDK·분석 도구는 설치 확인 과정에서 재사용합니다. 다른 PC로 ZIP을 옮기면 그 PC에서는 별도 환경을 구성합니다.
